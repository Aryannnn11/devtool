# DevTool

A developer productivity CLI built with Node.js and JavaScript.

DevTool provides a collection of useful utilities directly from the terminal, including developer notes, GitHub repository information, JSON utilities, file inspection, and UUID generation.

## Features

- 📝 Create, list, and remove developer notes
- 🐙 Fetch GitHub repository information
- 📄 Format and validate JSON
- 📁 Inspect files
- 🔑 Generate UUIDs
- 🎨 Colored terminal output
- 🧪 Automated unit tests
- ⚡ Fast command-line workflow

## Tech Stack

- Node.js
- JavaScript
- Commander.js — CLI framework
- Axios — HTTP requests
- Chalk — terminal styling
- Vitest — testing
- Node.js File System APIs
- Node.js Crypto APIs
